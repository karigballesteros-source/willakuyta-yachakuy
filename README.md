# willakuyta-yachakuy
Willakuyta Yachakuy es una app educativa interactiva donde estudiantes y curiosos aprenden la historia del Perú de forma divertida. Cubrimos desde la era precolombina (Caral, Chavín, Moche, Nazca, Inca y más de 13 civilizaciones) hasta la época colonial y la república peruana.
